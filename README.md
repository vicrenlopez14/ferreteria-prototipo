# Ferre

Prototipo navegable de una aplicación de ferretería creado como un único archivo HTML autocontenido. Incluye inicio de sesión, pantalla principal, catálogo, detalle de producto, carrito y confirmación de compra.

## Abrir el prototipo

Visita la versión publicada en GitHub Pages:

https://vicrenlopez14.github.io/ferreteria-prototipo/

También puedes descargar el repositorio y abrir `index.html` directamente en el navegador. No requiere instalación ni dependencias externas.

## Entregables

- `index.html`: prototipo responsive con CSS y JavaScript integrados.
- `Decisiones_de_UX_Ferre.docx`: explicación de dos decisiones de experiencia de usuario aplicadas al prototipo.
